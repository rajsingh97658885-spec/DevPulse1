# DevPulse

A real full-stack developer blogging platform.

## Stack

- Frontend: React + Vite + React Router + Tailwind CSS v4 + Lucide
- Backend: Node.js + Express
- Database: MongoDB + Mongoose
- Auth: JWT + bcryptjs
- API: REST

## Run backend

```bash
cd backend
npm install
npm run dev
```

## Run frontend

Open another terminal:

```bash
cd frontend
npm install
npm run dev
```

Frontend: http://localhost:5173
Backend: http://localhost:5000
